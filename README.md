## Novidades

Inimigos ativos com perseguição e sinalização dos ataques; no máximo dois atacantes simultâneos. Execução à distância por MMB / RS, com corrida que contorna paredes; esquiva, interrupção por dano ou perda de elegibilidade cancelam a aproximação. F11 alterna a IA para treinar; F5 no jogo reinicia a arena.
